# SL_tool_v1.0.1 for Windows 総合操作マニュアル

SL_tool_v1.0.1 は、認知言語機能評価および研究支援を目的とした総合言語評価ツールキットです。
7つの言語・構音課題（Naming, ActionDescription, Description, Repetition, ReadAloud, WordFluency, Diadochokinesis）を同一インターフェース上で実施・管理することができます。
対応OS：Windows専用（Windows 10/11推奨）

## 1. フォルダ構造

│   ├── cue.json                   # ヒント文字数・文言カスタマイズ（オプション）
│   └── synonyms.json              # 同義語・異名設定（オプション）

## 2. 刺激データの作成・配置ルール

刺激データは原則として `SL_tool_v1.0.1/stimuli/` 直下の各課題フォルダに配置します。`Naming`、`Description`、`ActionDescription` の各フォルダ配下には `test/`（評価用）や `task/`（訓練用）などのサブフォルダを作成して刺激セットを管理でき、実行時GUIから対象フォルダを選択することができます。

### 1. Naming（命名・呼称課題）

* **配置先**: `stimuli/Naming/`（サブフォルダ例: 評価用の `stimuli/Naming/test/`、訓練用の `stimuli/Naming/task/` 等をGUIから選択可能）

* **対応形式**: `.jpg`, `.jpeg`, `.png`

* **命名規則**: `数字_正答名.拡張子`

* **例**: `1_バナナ.jpg`, `2_りんご.png`

### 2. ActionDescription（行動描写課題）

* **配置先**: `stimuli/ActionDescription/`（サブフォルダ例: 評価用の `stimuli/ActionDescription/test/`、訓練用の `stimuli/ActionDescription/task/` 等をGUIから選択可能）

* **対応形式**: `.jpg`, `.jpeg`, `.png`

* **命名規則**: `数字_正答文.拡張子`

* **例**: `1_電車が鉄橋を渡っている.jpg`

### 3. Description（情景画説明課題）

* **配置先**: `stimuli/Description/`（サブフォルダ例: 評価用の `stimuli/Description/test/`、訓練用の `stimuli/Description/task/` 等をGUIから選択可能）

* **対応形式**: `.jpg`, `.jpeg`, `.png`

* **命名規則**: `数字_識別名.拡張子`

* **例**: `1_情景画.jpg`, `2_漫画の説明.png`

### 4. Repetition（復唱課題）

`stimuli/Repetition/` に `.wav` ファイルまたは `.txt` ファイルを配置できます。実行時のGUIでソース種別や実施項目を選択でき、事前試聴も可能です。

* **WAV音声の場合**:

  * **形式**: `.wav`

  * **命名規則**: `数字_正答文.wav`（例: `1_雨が降る.wav`）

* **TXTテキストの場合**:

  * **形式**: UTF-8 / CP932 テキストファイル（`#` で始まる行や空行は無視されます）

  * **記述例**:

    ```
    1_でんしゃ
    2_おとこの人が歩いている
    
    ```

  * **再生**: 機械音声（Windows TTS）で読み上げられます（`｜`, `|`, `／`, `/` などの記号は読み上げ前に除去されます）。

### 5. ReadAloud（音読課題）

画面上に提示されたテキストまたは画像を被験者が声に出して読む課題です（刺激の音声提示はありません）。`stimuli/ReadAloud/` 内の `.txt` ファイルまたは画像ファイル（`.jpg`, `.jpeg`, `.png`）を選択して実施できます。ヒント機能を有効にした場合、文字列がヒントとして提示されます。

* **テキストファイルの場合**:

  * **形式**: UTF-8テキストファイル（`数字_` などで始まる行を区切りとして1刺激として扱います）

  * **ヒント指定**: `|` または `｜` を入れると、ヒント提示時にその前までの文字列がヒントとして抽出されます（未指定時は先頭2文字がヒント文字列として提示されます）。

  * **ルビ・区切り表記**: `漢字［かんじ］` または `漢字[かんじ]` のルビ表記や、`／` `/` などの区切り記号に対応しています。

  * **記述例**:

    ```
    1_電車［でんしゃ］
    2_男の人が、｜歩いている
    3_北風［きたかぜ］と太陽［たいよう］が、｜力比べをしました。
    
    ```

* **画像ファイルの場合**:

  * **対応形式**: `.jpg`, `.jpeg`, `.png`

  * **正答テキスト参照**: 画像ファイルと同名（拡張子のみ `.txt`）のテキストファイルが `stimuli/ReadAloud/` 内に存在する場合、その内容が評価用テキスト（`eval_text`）として読み込まれます（存在しない場合はファイル名の拡張子を除いた部分が使用されます）。※画像選択時はヒント機能がオフ（`hintOFF`）、デフォルト制限時間は300秒となります。

### 6. WordFluency（語想起課題）

* 外部刺激ファイルは不要です。「動物」カテゴリーの名前を60秒間でできるだけ多く発話する課題です。

### 7. Diadochokinesis（ディアドココキネシス課題）

* 外部刺激ファイルは不要です。以下の4課題を順番に各5秒間測定します。

  1. `ぱ・ぱ・ぱ`（口唇音）

  2. `た・た・た`（歯茎音）

  3. `か・か・か`（軟口蓋音）

  4. `ぱ・た・か・ぱ・た・か`（連続運動）

## 3. オプション設定ファイル

### 1. ヒントのカスタマイズ (`Naming/cue.json`)

`Naming` 課題において、誤答時に提示するヒント（語頭音以外や特定の文字列）を `Naming/cue.json` で指定できます。

```
{
  "虫眼鏡": "虫",
  "洗濯ばさみ": "洗濯",
  "自動車": "自動",
  "冷蔵庫": "冷蔵",
  "柴犬": "柴",
  "トイプードル": "トイ"
}

```

### 2. 同義語・異名の正答判定 (`Naming/synonyms.json`)

`Naming` 課題において、標準辞書に加えて別称・異名を正答として扱う場合、`Naming/synonyms.json` に記述します。

```
{
  "ピーチ": ["もも"],
  "りんご": ["あっぷる"]
}

```

### 3. 語想起課題の辞書拡張 (`WordFluency/animal_dict.json`)

`WordFluency` 課題では、外部の `WordFluency/animal_dict.json`（JSON形式）から動物名辞書を読み込みます。このファイルを編集することで、動物名の表記揺れや語彙を追加できます。

```
{
  "マングース": ["マングース", "まんぐーす"],
  "イヌ": ["犬", "いぬ", "イヌ", "ワンコ", "わんこ"]
}

```

## 4. 実行手順

1. `SL_tool_v1.0.1/start.bat` をダブルクリックして起動します。

2. 画面の指示に従い「Subject ID」および「Subject Name（任意）」を入力します。

3. メニューから実行したい課題番号（`1`〜`7`、または `0` で終了）を選択します。

   * `1`: Naming

   * `2`: ActionDescription

   * `3`: Description

   * `4`: Repetition

   * `5`: ReadAloud

   * `6`: WordFluency

   * `7`: Diadochokinesis

4. 課題ごとの設定画面（GUI）で必要な項目を設定します（課題により表示される設定項目が異なります）。

   * **Whisperモデル選択**: `small`, `turbo`, `large` から選択（推奨・初期値：`turbo`）。

   * **刺激選択**: `Naming`, `Description`, `ActionDescription` では各課題フォルダ配下のサブフォルダ（評価用の `test`、訓練用の `task` 等）を選択でき、`Repetition` では WAV / TXT の選択と実施項目のチェック・試聴、`ReadAloud` では刺激ファイルの選択を行います。

   * **閾値設定**: 音声検出（無音／発話判定や録音トリガー・ピーク検出など）や判定に関わる閾値を GUI 上で調整できます。周囲の騒音環境や発話音量に合わせて調整してください。

   * **ヒント設定**: ヒントの「あり / なし」を選択（`Naming`, `ActionDescription`, `Repetition`, テキスト選択時の `ReadAloud`）。`ReadAloud` ではヒントありの場合に文字列がヒントとして提示されます。

   * **制限時間設定**: 1試行あたりの制限時間（秒）を **1以上の整数** で入力（`Naming`, `ActionDescription`, `Description`, `Repetition`, `ReadAloud`）。

   * ※ `WordFluency` は60秒固定、`Diadochokinesis` は各5秒固定で進行します（課題ごとの表示項目に従ってください）。

5. インストラクション画面で `Enter`（またはスペースキー）を押して課題を開始します。途中で終了したい場合は `Esc` キーを押してください。課題終了後はコマンドプロンプト画面に戻り、キー操作後にメニューへ戻ります。

## 5. 出力結果の保存先

測定結果は `SL_tool_v1.0.1/results/` フォルダ内に、以下の階層構造で保存されます。

```
results/
└── 被験者ID_被験者名/
    └── YYYYMMDD/
        └── セッションフォルダ名/
            ├── 結果CSV または 総合結果TXT
            └── 録音WAVファイル・分析結果TXT・スペクトログラム画像等

```

* **Naming / ActionDescription / Repetition / ReadAloud**: 試行ごとの結合録音（`.wav`）やセッションCSV（`.csv`）等が出力されます（`Repetition`・`ReadAloud` ではモーラ正答率、発話速度、高周波成分比率、フォルマント付きスペクトログラム画像 `*_spectrogram.png` なども生成されます）。

* **Description**: 試行ごとの録音（`.wav`）、談話・品詞分析結果（`.txt`）、統合結果（`*_total.csv`）が出力されます。

* **WordFluency**: 60秒間の録音（`*_recorded_speech.wav`）と動物名抽出・分析結果（`*_analysis_result.txt`）が出力されます。

* **Diadochokinesis**: 各課題の録音（`task_1_Pa_recorded.wav` 等）と音響ピーク解析による音節回数・秒間回数・ぱたかセット換算結果（`*_results.txt`）が出力されます。
