# SL_tool_v1.0.0 for Windows 総合操作マニュアル 

SL_tool_v1.0.0 は、認知言語機能評価および研究支援を目的とした総合言語評価ツールキットです。
6つの言語課題（Naming, ActionDescription, Description, Repetition, ReadAloud, WordFluency）を同一インターフェース上で実施・管理することができます。対応OS：Windows専用（Windows 10/11推奨）

---

## 1. フォルダ構造

```text
SL_tool_v1.0.0/
├── start.bat                  # 総合実験メニュー起動バッチ
├── Naming/                    # Naming タスク実行フォルダ
│   ├── Naming.exe             # 命名課題プログラム
│   ├── cue.json               # ヒント文字数カスタマイズ（オプション）
│   └── synonym.json           # 同義語設定（オプション）
├── ActionDescription/          # ActionDescription タスク実行フォルダ
│   └── ActionDescription.exe  # 行動描写課題プログラム
├── Description/               # Description タスク実行フォルダ
│   └── Description.exe        # 描写課題プログラム
├── Repetition/                # Repetition タスク実行フォルダ
│   └── Repetition.exe         # 復唱課題プログラム
├── ReadAloud/                 # ReadAloud タスク実行フォルダ
│   └── ReadAloud.exe          # 音読課題プログラム
├── WordFluency/               # WordFluency タスク実行フォルダ
│   ├── WordFluency.exe        # 語想起課題プログラム
│   └── animal_dict.py         # 動物名辞書拡張ファイル（オプション）
└── stimuli/                   # 刺激データ格納フォルダ
    ├── Naming/                # 命名課題用画像
    ├── ActionDescription/     # 行動描写課題用画像
    ├── Description/           # 描写課題用画像
    ├── Repetition/            # 復唱課題用音声
    └── ReadAloud/             # 音読課題用テキスト (ReadAloud.txt)
```

## 2. 刺激データの作成・配置ルール

刺激データはすべて `SL_tool_v1.0.0/stimuli/` 直下の各課題フォルダに配置します。

### 1. Naming（命名課題）
- **配置先**: `stimuli/Naming/`
- **形式**: JPEG画像（`.jpg`）
- **命名規則**: `数字_正答名.jpg`
- **例**: `1_バナナ.jpg`, `2_りんご.jpg`

### 2. ActionDescription（行動描写課題）
- **配置先**: `stimuli/ActionDescription/`
- **形式**: JPEG画像（`.jpg`）
- **命名規則**: `数字_正答文.jpg`
- **例**: `1_電車が鉄橋を渡っている.jpg`

### 3. Description（描写課題）
- **配置先**: `stimuli/Description/`
- **形式**: JPEG画像（`.jpg`）
- **命名規則**: `数字_識別名.jpg`
- **例**: `1_情景画.jpg`, `2_漫画の説明.jpg`

### 4. Repetition（復唱課題）
- **配置先**: `stimuli/Repetition/`
- **形式**: WAV音声（`.wav`）
- **命名規則**: `数字_正答文.wav`
- **例**: `1_雨が降る.wav`（人の声等を録音）

### 5. ReadAloud（音読課題）
- **配置先**: `stimuli/ReadAloud/ReadAloud.txt`
- **形式**: UTF-8テキストファイル（1行につき1刺激）
- **ヒント指定**: `|`（縦棒）を入れると、`|` より前の文字列がヒント音声として提示されます。
- **例**:
  ```text
  1_電車
  2_男の人が、|歩いている
  3_北風と太陽が、|力比べをしました。
  ```

## 3. オプション設定ファイル

### 1. ヒント文字数の変更 (`Naming/cue.json`)
デフォルトは語頭音提示ですが、`Naming/cue.json` を配置・編集することでヒント範囲を調整できます。

```json
{
  "虫眼鏡": "虫",
  "洗濯ばさみ": "洗濯",
  "自動車": "自動",
  "冷蔵庫": "冷蔵",
  "柴犬": "柴",
  "トイプードル": "トイ"
}
```

### 2. 同義語・異名の正答判定 (`Naming/synonym.json`)
同じ意味を持つ別称・異名を正答として判定させる場合、`Naming/synonym.json` に記述します。

```json
{
  "りんご": ["あっぷる"]
}
```

### 3. 語想起課題の辞書拡張 (`WordFluency/animal_dict.py`)
`WordFluency` 課題において、`WordFluency/animal_dict.py` 内の辞書データを編集することで、ごく低頻度語の動物名や表記揺れを正答判定に含めることができます。

```python
# animal_dict.py の設定例
animal_dict = {
    "マングース": ["マングース", "まんぐーす"],
    "イヌ": ["犬", "いぬ", "イヌ", "ワンコ", "わんこ"]
}
```

## 4. 実行手順

1. `SL_tool_v1.0.0/start.bat` をダブルクリックして起動します。
2. 画面の指示に従い「被験者ID」および「被験者名（任意）」を入力します。
3. 実行したい課題番号（1〜6）を選択します。
4. 音声認識モデル、ヒント有り無し、制限時間を設定し、課題開始します。
5. 課題終了後、自動的にメインメニューに戻ります。
